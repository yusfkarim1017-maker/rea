# کۆمەڵە ئامرازی نۆژەنکردنەوەی APK

ئەم بوخچەیە چوار شت دەکات: **پشکنین**، **دووبارە دروستکردنەوە (rebuild)**،
**پشکنینی گونجاوی**، و **دروستکردنی پڕۆژەیەکی نوێی هاوشێوە** لەسەر بنەمای
ئەوەی لە ئەپەکە تێیگەیشتوویت. هیچ کام لەم ئامرازانە ئەپەکە لەسەر ئامێر
ناجووڵێنن و هیچ داتایەک بۆ ئینتەرنێت نانێرن.

---

## ٠. پێداویستی

- **Python 3.10+** بۆ `apk_report.py` و `make_scaffold.py` و `apk_verify.py`
- **JDK 17 یان نوێتر** تەنها بۆ هەنگاوی دووبارە دروستکردنەوە
- ئینتەرنێت تەنها یەکەم جار (بۆ داگرتنی Apktool و uber-apk-signer)

دامەزراندنی ئامرازی پایتۆن (یەک جار):

```bash
python3 -m venv .venv
# لینوکس / ماک:
. .venv/bin/activate
# ویندۆز:
.venv\Scripts\activate

pip install androguard
```

---

## ١. پشکنین — بزانە چی لە ناو APK دایە

```bash
python apk_report.py app.apk -o work/
```

دوو فایل دروست دەکات:

- `work/app.report.json` — داتای ئامێری (بۆ ئەیجێنتەکان)
- `work/app.report.md` — ڕاپۆرتی خوێندنەوە بۆ تۆ

ناوەڕۆکی ڕاپۆرت:

- ناوی پاکێج، وەشان، min/target SDK، شاشەی سەرەکی
- واژووەکان (v1/v2/v3) + فینگرپرینتی SHA-256 ی بڕوانامە
- مۆڵەتەکان و ئەو پێکهاتانەی کە بۆ دەرەوە کراوەتن (exported)
- ژمارەی پۆلەکان و توخمە سەرەکییەکان لە هەر فایلی DEX
- SDK و چوارچێوە بەکارهێنراوەکان (Flutter، React Native، Unity، .NET، Cordova…)
- ABI ی کۆدە نەیتیوەکان
- نیشانەکانی پاراستن/دژە-دەستکاری لەگەڵ ئەو دەقەی کە دۆزراوەتەوە (بۆیە دەزانیت چرا هۆشدارییەک هەیە)
- مەزەندەی مەترسی بۆ دووبارە دروستکردنەوە

## ٢. دووبارە دروستکردنەوە (Rebuild)

### ویندۆز (PowerShell)

```powershell
.\rebuild_apk.ps1 -Apk app.apk -OutDir work
```

### لینوکس / ماک

```bash
./rebuild_apk.sh app.apk -o work
```

سکریپت خۆی ئەم هەنگاوانە دەکات:

1. دڵنیا دەبێتەوە کە Java 17+ هەیە
2. Apktool و uber-apk-signer دادەگرێت (یەکەم جار) و ئەگەر ڕیلیزەکە digest بڵاوکردبێتەوە، SHA-256 پشکنین دەکات
3. APK دەکاتەوە (`apktool d`) بۆ `work/decoded`
4. دووبارە دروستی دەکاتەوە (`apktool b`)
5. زیپ-ئەلاین و واژوو دەکات بە v1+v2+v3
6. ئەنجام: `work/signed/rebuilt-signed.apk`

### دەستکاریکردن پێش دروستکردن

هەر شتێک لە `work/decoded/` دەتوانی بگۆڕی (ناو، ئایکۆن، لینک، دەق،
مانیفێست…). پاشان بەم شێوەیە دووبارە دروستی بکەرەوە بەبێ ئەوەی دەستکارییەکانت
بفەوتێن:

```bash
./rebuild_apk.sh app.apk -o work --reuse      # ویندۆز: -ReuseDecoded
```

### بە کلیلی خۆت واژوو بکە

```powershell
.\rebuild_apk.ps1 -Apk app.apk -Keystore my.jks -KsAlias mykey -StorePass PASS -KeyPass PASS
```

ئەگەر کلیل نەدەیت، سکریپت خۆی `work/rebuilt.keystore` دروست دەکات.

## ٣. پشکنینی گونجاوی — ئایا دروستکراوەکە هەمان ئەپە؟

```bash
python apk_verify.py app.apk work/signed/rebuilt-signed.apk --json work/verify.json
```

چی بەراورد دەکات:

| بەش          | شێواز                                                               |
| ------------ | ------------------------------------------------------------------- |
| ناوەڕۆکی zip | CRC32 + قەبارەی هەر تۆمارێک (identical / changed / added / removed) |
| مانیفێست     | پاکێج، وەشان، SDK، مۆڵەت، پێکهاتەکان، شاشەی سەرەکی                  |
| واژوو        | شێمەکان و فینگرپرینتی بڕوانامە                                      |
| کۆد          | هەموو ناوی پۆلەکانی DEX لە هەردوو فایل                              |

ئەنجام یەکێکە لە: `identical`، `equivalent`، `diverged`.
کۆدی چوونەدەرەوە 0 بۆ دوو حاڵەتی یەکەم.

## ٤. دروستکردنی ئەپێکی نوێی هاوشێوە

```bash
python make_scaffold.py app.apk -o new/
```

پڕۆژەیەکی ئاسایی Kotlin/Gradle دروست دەکات کە:

- هەمان پاکێج و هەمان ئاستی SDK و هەمان مۆڵەتەکانی هەیە
- بۆ هەر شاشەیەکی ئەپی سەرەکی، شاشەیەکی نموونەیی (stub) هەیە
- `PARITY.md` پێت دەدات وەک لیستی کار بۆ ئەوەی بزانیت چی ماوە

**هیچ کۆدی دیکۆمپایلکراو لە ناوی نییە** — ئەمە خاڵێکی پاکە بۆ دووبارە
دروستکردنەوەی ڕەفتار بەپێی ئەوەی خۆت پشکنیوت.

دروستکردن:

```bash
cd new/<ناوی پڕۆژە>
gradle wrapper --gradle-version 8.7
gradle :app:assembleDebug
```

یان لە Android Studio: `File > Open` و بوخچەکە هەڵبژێرە.

## چ ڕاستییەک دەبێت بزانیت

**دووبارە دروستکردن هیچ کات «سەد لە سەد بایت-بە-بایت وەک خۆی» نابێت.**
هۆکارەکان:

1. `classes.dex` و `resources.arsc` دووبارە کۆمپایل دەکرێنەوە
2. میتاداتای zip و ڕیزکردنی تۆمارەکان دەگۆڕێت
3. بلۆکی واژوو بە کلیلی تۆ لە نوێوە دروست دەکرێت — ناتوانرێت کلیلی
   ئەپی سەرەکی بهێنرێتەوە
4. ئەگەر ئەپەکە پاکەر یان پشکنینی دەستکاری هەبێت (Play Integrity،
   jiagu/360، Frida-detection)، ڕەنگە دروستکراوەکە ڕەت بکرێتەوە

بەڵام ئەمە **دەگاتە ئەنجامی کارا**: هەمان شاشەکان، هەمان پێکهاتە، هەمان
ڕەفتار ئەگەر کۆدەکە بە دروستی بگەڕێتەوە. بۆ دڵنیایی، هەمیشە لەسەر ئامێر
تاقیی بکەرەوە.

**ئەو شتانەی هیچ کات ناگەڕێنەوە:** کلیلی واژووی ڕەسەن، لۆژیکی سێرڤەر،
کلیلەکانی API ی ناو ئەپ، داتای بەکارهێنەران، مۆڵەتەکانی سێرڤەر.

## سنووری بەکارهێنان

ئەم ئامرازانە بۆ ئەپەی **خۆت** یان ئەپێک کە **مۆڵەتی دەستکاریت هەیە**
دروستکراون. دووبارە دروستکردنەوە لە ڕووی تەکنیکییەوە کار دەکات، بەڵام
بڵاوکردنەوەی ئەپی کەسێکی تر وەک هی خۆت کێشەی مافی چاپکردنە.
ئەگەر مەبەستت ئەپێکی هاوشێوە بێت، ڕێگای ٤ (scaffold) بەکاربهێنە.
